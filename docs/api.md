# REST API Specification - AI Smart Health Monitor

Base URL: `http://localhost:5000/api`

## Authentication Header
Protected endpoints require JWT in the `Authorization` header:
`Authorization: Bearer <token>`

---

## Endpoints

### 1. Health Check
* **GET** `/health`
* **Response**: `200 OK`
  ```json
  {
    "status": "ok",
    "timestamp": "2026-08-19T11:00:00.000Z",
    "db": "connected",
    "aiService": "configured"
  }
  ```

---

### 2. User Authentication

#### Register User
* **POST** `/auth/register`
* **Body**:
  ```json
  {
    "email": "user@example.com",
    "password": "SecurePassword123",
    "name": "Alex Smith",
    "deviceId": "ESP32-HEALTH-001"
  }
  ```
* **Response**: `201 Created`
  ```json
  {
    "token": "eyJhbGciOi...",
    "user": {
      "id": "usr_123",
      "email": "user@example.com",
      "name": "Alex Smith",
      "deviceId": "ESP32-HEALTH-001"
    }
  }
  ```

#### Login User
* **POST** `/auth/login`
* **Body**:
  ```json
  {
    "email": "user@example.com",
    "password": "SecurePassword123"
  }
  ```
* **Response**: `200 OK` (returns token and user details).

#### Get Current User Profile
* **GET** `/auth/me` (Protected)
* **Response**: `200 OK` with user details.

---

### 3. Sensor Readings

#### Ingest Reading (from ESP32 or Demo Engine)
* **POST** `/readings`
* **Headers**: `Content-Type: application/json`
* **Body**:
  ```json
  {
    "deviceId": "ESP32-HEALTH-001",
    "heartRate": 76,
    "spo2": 98,
    "temperature": 36.6,
    "timestamp": "2026-08-19T11:00:00Z"
  }
  ```
* **Response**: `201 Created`
  ```json
  {
    "success": true,
    "data": {
      "id": "rdg_456",
      "deviceId": "ESP32-HEALTH-001",
      "heartRate": 76,
      "spo2": 98,
      "temperature": 36.6,
      "status": "NORMAL",
      "createdAt": "2026-08-19T11:00:00.000Z"
    }
  }
  ```

#### Get Latest Reading
* **GET** `/readings/latest?deviceId=ESP32-HEALTH-001`
* **Response**: `200 OK`
  ```json
  {
    "reading": {
      "heartRate": 76,
      "spo2": 98,
      "temperature": 36.6,
      "status": "NORMAL",
      "deviceId": "ESP32-HEALTH-001",
      "createdAt": "2026-08-19T11:00:00.000Z"
    }
  }
  ```

#### Get Readings History
* **GET** `/readings/history?range=24h&deviceId=ESP32-HEALTH-001`
* **Query Parameters**:
  - `range`: `24h` | `7d` | `30d`
  - `limit`: max results count (default 100)
* **Response**: `200 OK` with array of historical readings.

### 4. AI Analytics (Google Gemini)

#### Request AI Reading Analysis
* **POST** `/ai/analyze`
* **Body**:
  ```json
  {
    "heartRate": 88,
    "spo2": 95,
    "temperature": 37.8,
    "symptoms": "Mild headache and feeling warm after workout",
    "deviceId": "ESP32-HEALTH-001"
  }
  ```
* **Response**: `200 OK`
  ```json
  {
    "summary": "Your temperature is slightly elevated at 37.8°C with a heart rate of 88 BPM.",
    "explanations": [
      "Light exercise or dehydration can temporarily increase body temperature and heart rate.",
      "Mild headache can accompany post-workout fatigue or insufficient fluid intake."
    ],
    "recheckRecommended": true,
    "safetyGuidance": "Rest in a cool room, hydrate with water, and re-check measurements in 30 minutes.",
    "questionsForDoctor": [
      "What baseline temperature is typical for my age?",
      "When should a mild temperature elevation be evaluated?"
    ],
    "disclaimer": "This analysis is generated by AI for educational purposes and is NOT a medical diagnosis."
  }
  ```

#### AI Health Chat Assistant
* **POST** `/ai/chat`
* **Body**:
  ```json
  {
    "message": "Why does heart rate increase after exercise?",
    "deviceId": "ESP32-HEALTH-001"
  }
  ```
* **Response**: `200 OK`
  ```json
  {
    "reply": "During exercise, your muscles require more oxygen and blood circulation. To meet this demand, your heart beats faster...",
    "disclaimer": "This response is educational and not medical advice."
  }
  ```

### 5. Device Status & Heartbeat

#### Get Device Status
* **GET** `/device/status?deviceId=ESP32-HEALTH-001`
* **Response**: `200 OK`
  ```json
  {
    "deviceId": "ESP32-HEALTH-001",
    "isOnline": true,
    "lastPing": "2026-08-19T11:00:00.000Z",
    "rssi": -62,
    "firmwareVersion": "1.0.0"
  }
  ```

#### Post Device Heartbeat
* **POST** `/device/heartbeat`
* **Body**: `{ "deviceId": "ESP32-HEALTH-001", "rssi": -62 }`
* **Response**: `200 OK`
